# Example 01 — Coastal Grade, client update letter

One complete worked run, in four numbered files read in order:
`01-what-they-sent.md` (the owner's own document as handed over),
`02-what-the-kit-said.md` (the extraction conversation in the kit's words),
`03-the-checks.md` (every check that ran and what it flagged), and
`04-the-receipt.txt` (the record written when the owner accepted the result).

Read it to see the flow. It is not the install check -- that takes one of your
own documents end to end.
