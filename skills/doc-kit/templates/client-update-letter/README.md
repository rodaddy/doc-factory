# `client-update-letter` -- the FALLBACK skeleton

Not the demo and not the first run. It exists only for a customer who genuinely
has nothing on file, and the kit labels it as a starter skeleton to be replaced
the first time they send a real one. Measured at 68 words of locked prose, it
fails this kit's own 150-word refusal gate, which is the correct signal.

Files: `template.md` (the fields and locked prose), `form.html` (the browser
fill-in page), `style.html` plus `style-notes.md` (the locked look, read by the
AI and never opened by the customer), `review-checks.md` (class checks and any
waived), `sources/` (provenance), and `history/` (one file per finished run).

Never overwritten by an install or upgrade: once used, it holds the customer's
own checks, provenance, and run history.
