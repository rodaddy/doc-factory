# `sources/` -- where the wording came from

The provenance record for this template, so every finished document can point
each section back to the wording it drew from, by locked-paragraph number and
source document.

- `locked-prose.md` -- the locked paragraphs, numbered L1, L2, and so on.
- `source-record.md` -- which of the owner's documents each paragraph came out
  of, who supplied it, and when.

For the shipped fallback skeleton both files record that there is NO customer
source, which is the point of the fallback.
